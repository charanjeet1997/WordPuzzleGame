# Inspector Pro

Inspector Pro is a powerful Unity editor extension that enhances the default inspector with a range of features designed to streamline your workflow.

## Features

*   **Component Clipboard:** Copy and paste components between GameObjects with ease.
*   **Enhanced Prefab Handling:** A dedicated prefab section allows you to open, select, and manage prefab overrides directly from the inspector.
*   **Component Filtering:** Quickly find components by name or type using the built-in search and filter bar.
*   **Improved UI:** Inspector Pro offers a more organized and feature-rich component inspector, including:
    *   A context menu for common actions like moving, copying, and removing components.
    *   A preset selector for quickly applying component settings.
*   **Material Inspector:** Inspect and modify materials directly within the component view, saving you time and clicks.

## How to Use

1.  Open the Inspector Pro window by navigating to **Tools > Inspector Pro**.
2.  Select a GameObject in your scene to view it in the Inspector Pro window.
3.  Use the search bar and type filters to narrow down the list of components.
4.  Right-click on a component to access the context menu for additional actions.
5.  Use the "Clipboard" button to open the Component Clipboard and manage copied components.

## Installation

To install Inspector Pro, simply add the `InspectorPro` folder to your Unity project's `Assets` directory.
