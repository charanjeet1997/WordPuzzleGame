These replaced an earlier set of chillstep / house loops, which were energetic dance tracks
at odds with a slow word puzzle - the wrong music for a game people play to unwind.

Adding a track: drop any AudioClip into this folder and re-run Aurora Words > Setup Scene.
MusicPlayer's playlist is rebuilt from every clip here.

Note on size: BGM_Chilly_Bells.wav is ~23 MB as source. Unity compresses it to streaming
Vorbis in the build (see MusicImportSettings.cs), so the shipped size is far smaller - but
delete it if repository size matters more than having a fourth track.
